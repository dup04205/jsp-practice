# 7강 모듈화된 JSP 페이지 만들기

| 파일 | 내용 |
|---|---|
| `main.jsp` | jsp:include로 userinfo.jsp 포함 |
| `userinfo.jsp` | 포함되는 사용자 정보 조각 |
| `7-4.jsp` | jsp:param으로 파라미터 전달 (7-4.jsp?name=James) |
| `7-5.jsp` | 같은 이름 파라미터 모두 읽기 |
| `7-6.jsp` | include 지시어로 7-7.jsp 포함 |
| `7-7.jsp` | 정적 include 조각(단독 실행 불가) |
| `7-8.jsp` | request 속성 저장 후 jsp:forward |
| `7-9.jsp` | forward 대상 페이지 |
