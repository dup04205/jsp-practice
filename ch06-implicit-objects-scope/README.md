# 6강 내장 객체와 영역

| 파일 | 내용 |
|---|---|
| `WEB-INF/web.xml` | context-param 설정 |
| `6-1.jsp` | application 초기화 파라미터 출력 |
| `6-2.jsp` | 웹 컨테이너 정보 출력 |
| `6-5.jsp` | out 객체 버퍼 정보 |
| `request-set.jsp` | request 속성 저장 후 forward |
| `request-get.jsp` | forward된 페이지에서 속성 읽기 |
| `boxing.jsp` | 기본형 속성의 박싱/언박싱 |
